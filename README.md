# جولدن جليز دونات

واجهة متجر عربية لعرض الدونات وطلبها، مبنية باستخدام Next.js وTypeScript وTailwind CSS وSupabase.

## التشغيل

```bash
npm install
npm run dev
```

يستخدم المتجر `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` لعرض المنتجات المتاحة من جدول `donuts`. قيم التصنيفات المستخدمة هي `دونات محشي` و`ميني دونات`.

## إعداد الطلبات

إرسال الطلبات يتم من خلال Next.js Server Action يستخدم Supabase Server Client والمفتاح العام فقط. يتم التحقق من رقم العميل والمنتجات وحساب الإجمالي وإنشاء الطلب وعناصره داخل دالة قاعدة بيانات محدودة الصلاحيات؛ لا يحتاج المتجر إلى مفتاح `service_role` أو سياسات إدخال عامة على جداول الطلبات. يمكن للعميل الطلب كزائر دون حساب.

يُحفظ العنوان والمنطقة وملاحظات الطلب في حقل عنوان العميل الحالي، لأن جدول `orders` الحالي لا يحتوي أعمدة مستقلة لهذه البيانات. رسوم التوصيل لكل منطقة، وطرق الدفع، وتفاصيل InstaPay، والتواصل، وإتاحة الطلبات تُدار من إعدادات لوحة التحكم.

يُرفع إثبات التحويل إلى bucket `payment_proof` الموجود والخاص، باستخدام المفتاح العام وسياسات Storage محدودة على الطلبات ذات الصلة. لا يُعد رفع الصورة تأكيدًا للدفع. يمكن تفعيل معاينة العميل للصورة لمدة 15 دقيقة عبر توقيع الوصول الاختياري:

```env
PAYMENT_PROOF_SIGNING_SECRET=<server-only secret>
```

عدم ضبط هذا السر لا يمنع الطلب أو رفع الإيصال؛ تظل معاينة الإيصال متاحة للأدمن من لوحة التحكم.
